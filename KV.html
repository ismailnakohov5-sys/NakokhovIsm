Ответы на контрольные вопросы

1. Что такое система контроля версий?

Система контроля версий — это программа, которая позволяет отслеживать изменения файлов, сохранять историю изменений и возвращаться к предыдущим версиям проекта.

2. К какому типу VCS относится Git? В чем главное отличие?

Git относится к распределённым системам контроля версий. Главное отличие заключается в том, что каждый пользователь имеет полную копию репозитория на своём компьютере.

3. В чем заключается преимущество использования Git?

Git позволяет сохранять историю изменений, работать над проектом совместно, быстро восстанавливать файлы и удобно управлять версиями проекта.

4. Какие команды Git вы знаете?

git init, git add, git commit, git push, git pull, git status, git branch, git checkout.

5. В чем отличие Git и GitHub?

Git — это система контроля версий, которая работает на компьютере пользователя. GitHub — это онлайн-сервис для хранения Git-репозиториев и совместной работы.
